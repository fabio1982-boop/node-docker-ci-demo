Como demonstrar a atualização no vídeo

  1. Abra o site (ex: http://localhost:8080 ou o IP público da EC2).
  2. Clique em "Chamar API" e mostre a resposta com version: "v1".
  3. No código, troque "v1" por "v2" em backend/server.js, commit e push para a branch master.
  4. Aguarde o GitHub Actions publicar a atualização no servidor e recarregue a página.
  5. Mostre que agora a API retorna version: "v2".
